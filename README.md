# 교과목 소개 사이트 — 사용법과 배포 안내

고려대학교 ***학과 「***」 교과목을 소개하는 정적 웹사이트입니다. 서버·설치 없이 `index.html`을 열면 동작합니다.

## 1. 먼저 읽어 주세요 (중요한 한계)

이 사이트에는 서버가 없습니다. 그래서 **투표·수강 신청서·출석·과제 파일·공지·수강생 명단은 입력한 사람의 브라우저(localStorage, IndexedDB) 안에만 저장됩니다.**

| 상황 | 결과 |
|---|---|
| 수강생이 자기 휴대폰에서 투표·신청·출석·과제 제출 | 그 휴대폰에만 저장됨. **관리자 화면에는 보이지 않음** |
| 같은 브라우저의 다른 탭 | 실시간으로 함께 갱신됨 |
| 교수자가 자기 PC에서 관리자 화면으로 수강생을 대신 입력 | 그 PC에서는 모두 확인·내려받기 가능 |

따라서 **한 대의 컴퓨터를 공유하는 환경(강의실 키오스크, 실습실 PC, 시연)** 에서는 지금 그대로 쓸 수 있습니다. 수강생 각자의 기기에서 모은 데이터를 교수자가 한 곳에서 보려면 **데이터를 모아 줄 서버(예: Firebase, Supabase, Google Apps Script)** 가 필요합니다. 이 연동은 아직 포함되어 있지 않습니다.

보안도 같은 이유로 제한적입니다.
- 관리자·수강생 로그인은 **브라우저 안에서만 확인하는 방식**입니다. 코드를 아는 사람이 브라우저 개발자 도구로 우회할 수 있으므로, 성적·개인정보처럼 민감한 용도로는 쓰지 마세요.
- 비밀번호는 코드에 평문으로 들어 있지 않고 솔트와 반복 해시로만 저장되지만, 해시 자체는 공개 파일에서 보입니다. 길고 추측하기 어려운 비밀번호를 쓰세요.
- 수강생의 처음 비밀번호는 학번과 같습니다. 개인정보 수집 시에는 학교의 개인정보 보호 지침을 따르세요.

## 2. 파일 구성

| 파일 | 역할 | 고치나요? |
|---|---|---|
| `index.html` | 페이지 뼈대 | 아니요 |
| `config.js` | **사이트의 모든 내용·설정** | **예** |
| `style.css` | 디자인(분홍·보라 색상은 맨 위 `:root`) | 색을 바꿀 때만 |
| `store.js` | 저장소·해시·CSV 도구 | 아니요 |
| `features.js` | 투표, 신청서, 로그인·출석·과제, 팝업, 폭죽 | 아니요 |
| `course.js` | 한눈에 보기, 통계 카드, 장점 슬라이드, 도구, 준비물, 주차별 커리큘럼, 달력 | 아니요 |
| `app.js` | 설정을 읽어 화면을 그림 | 아니요 |
| `admin.js` | 관리자 화면 | 아니요 |

## 3. 열기

`index.html`을 더블클릭하면 브라우저에서 열립니다. 모든 파일을 같은 폴더에 두세요.

## 4. 내용 수정하기 (두 가지 방법)

### 방법 A. `config.js`를 직접 수정 (영구 반영, 권장)
메모장이나 VS Code로 `config.js`를 열어 따옴표 안의 글을 고칩니다. 맨 위의 `department`, `courseName`, `pageTitle`, `footerText`에 있는 `***`를 실제 학과명·교과목명으로 바꾸는 것부터 시작하세요. 저장 후 페이지를 새로고침하면 반영됩니다.

### 방법 B. 관리자 화면에서 수정
1. 오른쪽 위 🔒 → 관리자 비밀번호 입력
2. **사이트 편집** 탭에서 영역을 고르고 내용을 수정 (항목 추가·삭제·순서 이동 가능)
3. **저장하고 사이트에 적용** 클릭

⚠️ 이 방법의 저장분은 **이 브라우저에만** 적용됩니다. 모든 방문자에게 보이려면 **설정·백업 → config.js 로 저장**으로 내려받은 파일을 사이트의 `config.js`와 바꿔 올리세요. 화면에서 고친 내용이 `config.js` 원본보다 우선하므로, `config.js`를 새로 교체한 뒤에는 **사이트 편집 → 원본(config.js)으로 되돌리기**를 눌러야 새 파일이 보입니다.

## 4-1. 화면 구성과 일정·과제 설정

페이지는 위에서부터 **첫 화면 → 한눈에 보기(일정·시간·수업 방식·수강 대상) → 통계 카드 → 공지 → 프로그램 소개(장점 슬라이드) → 커리큘럼(주차별 + 달력) → 실습 도구 → 수강 준비물 → 수강 안내 → 투표 → 수강 신청 → 내 강의실 → FAQ → 푸터(교수자)** 순서입니다. 순서는 `config.js`의 `nav` 배열 순서이고, `menu: false`로 두면 상단 메뉴에는 표시하지 않고 섹션만 보여줍니다.

### 주차별 일정 (`curriculum`)
- `startDate`(첫 수업일)만 정하면 **7일 간격으로 15주(또는 `weeks` 개수만큼)의 날짜가 자동 계산**되고, 달력의 수업일 표시도 같은 값에서 만들어집니다. 첫 수업일이 화요일이면 매주 화요일입니다.
- 한 주만 날짜·시간·장소를 바꾸려면 그 주의 `date`(예: `"2026-05-06"`), `time`, `place`를 적으세요. 비워두면 전체 기본값을 씁니다. 휴강으로 이후 주차가 밀리면 이후 주차의 `date`도 직접 적어야 합니다.
- `content`는 한 줄이 한 항목입니다. `videos`에는 `{ title, url }`을 넣습니다(`http://`, `https://` 주소만 표시).
- **과제**는 `assignment`의 `title`과 `due`(예: `"2026-03-24T23:59"`)를 모두 적은 주차에만 나타납니다. 그 주차 카드에 설명, 마감 일시, **마감까지 남은 시간(D-day, 30초마다 갱신)**, 제출 버튼이 표시되고, ‘내 강의실’의 과제 선택 목록에도 자동으로 들어갑니다. `id`는 한 번 정하면 바꾸지 마세요(제출 기록과 연결됨).
- `overview`의 문구에 `{start}` `{end}` `{weeks}` `{time}` `{place}` `{weekday}`를 쓰면 커리큘럼 설정에서 자동으로 채워집니다. 통계 카드는 `source`가 `weeks`/`tools`이면 주차 수·도구 수를 자동으로 셉니다.
- 샘플 값(주제, 도구 이름, 저술 수 3권, 강의 경력 10년, 마감일 등)은 **예시**이니 실제 내용으로 바꿔 주세요.

## 5. 관리자 화면 사용법

🔒 아이콘 → 비밀번호. 5번 틀리면 30초간 잠깁니다. (초기 비밀번호는 전달받은 안내를 확인하고 **바로 변경**하세요.)

| 탭 | 할 수 있는 일 |
|---|---|
| 사이트 편집 | 기본 정보, 첫 화면, 통계, 장점 슬라이드, 주차별 일정·영상·과제, 도구, 준비물, 투표 주제, 팝업 문구 수정 (항목 추가·삭제·순서 이동) |
| 수강생 | `학번, 이름`을 한 줄씩 붙여 넣어 명단 등록(엑셀 복사 가능), 비밀번호 초기화, 삭제 |
| 공지 | 공지 작성·삭제 (최근 3개가 첫 화면 아래에 표시) |
| 출석 | 기록 조회, **출석부(학생×날짜)** CSV와 기록 CSV |
| 과제 | 제출 목록, 파일 개별 다운로드, CSV |
| 수강 신청 | 신청서 조회·삭제, CSV |
| 투표 | 득표 현황, CSV, 초기화 |
| 설정·백업 | 설정 파일 저장·불러오기, `config.js` 내보내기, 비밀번호 변경, 데이터 백업·복원 |

CSV는 UTF-8(BOM) 형식이라 **엑셀에서 더블클릭하면 한글이 깨지지 않고 열립니다.** `=`, `+`, `-`, `@`로 시작하는 값은 엑셀 수식으로 실행되지 않도록 자동 처리됩니다.

### 비밀번호 바꾸는 순서
1. **설정·백업 → 관리자 비밀번호 변경**에서 새 비밀번호(8자 이상) 입력
2. 모든 방문자에게 적용하려면 같은 탭의 **config.js 로 저장** → 내려받은 파일로 사이트의 `config.js` 교체 (해시가 함께 들어 있습니다)

## 6. 수강생 사용법

| 메뉴 | 동작 |
|---|---|
| 투표 | 주제를 고르고 투표. 브라우저당 1표, 언제든 변경 가능. 결과는 막대그래프로 즉시 갱신 |
| 수강 신청 | 신청서 작성. 빠진 항목과 형식 오류(학번·이메일·연락처)를 목록으로 알려 줌. 같은 학번은 중복 제출 불가 |
| 커리큘럼 | 주차를 눌러 날짜·시간·장소·학습 내용·참고 영상을 펼쳐 보기(모두 펼치기/접기 가능). 과제가 있는 주는 설명, 마감 일시, 남은 시간, 제출 버튼 표시 |
| 수업 달력 | 달을 넘겨 보며 수업일(매주 화요일)과 과제 마감일 확인. 날짜를 누르면 그날 수업 내용이 나오고, ‘주차 상세 보기’로 해당 주차 카드를 펼침 |
| 내 강의실 | 학번·비밀번호로 로그인 → 하루 1회 출석 체크, 과제 선택 후 파일 제출(최대 용량은 `config.js`의 `maxFileMB`, 기본 10MB). 같은 과제를 다시 내면 이전 파일이 교체되고, 마감 일시가 지나면 "지각"으로 표시. 주차 카드의 ‘과제 제출’ 버튼으로도 제출 가능(로그인 필요) |

로그인은 **관리자가 먼저 수강생 명단을 등록해야** 가능합니다. 처음 방문하면 폭죽 효과가 나오고, 잠시 뒤 수강 신청 안내 팝업이 뜹니다. 팝업의 **오늘 하루 보지 않기**를 체크하고 닫으면 그날은 다시 뜨지 않습니다. 운영체제에서 "움직임 줄이기"를 켠 사용자에게는 폭죽과 벚꽃잎을 보여주지 않습니다.

## 7. 배포 방법

정적 파일뿐이라 어떤 정적 호스팅에도 올릴 수 있습니다. **폴더 안의 모든 파일**을 올리세요. (`.claude` 폴더는 필요 없습니다.)

### GitHub Pages (무료)
1. GitHub에서 새 저장소를 만들고 모든 파일을 업로드
2. Settings → Pages → Branch를 `main` / `(root)`로 선택 후 저장
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/`로 접속

### Netlify Drop (가장 쉬움)
1. <https://app.netlify.com/drop> 에 폴더를 통째로 끌어다 놓기
2. 발급된 주소로 접속 (사이트 이름은 설정에서 변경 가능)

### 학과·학교 웹 서버
정적 파일 업로드가 가능한 공간에 폴더를 그대로 복사하면 됩니다. 학교 호스팅 정책은 담당 부서에 확인하세요.

### 배포 전 체크리스트
- [ ] `config.js`의 `***`를 모두 실제 내용으로 교체
- [ ] 관리자 비밀번호를 바꾸고 `config.js`로 내보낸 파일을 반영
- [ ] 수강 신청 기간, 수업 시간, 과제 마감일 등 날짜 확인
- [ ] 휴대폰에서 한 번 열어 확인

## 8. 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| 내용을 `config.js`에서 고쳤는데 그대로예요 | 관리자 화면에서 고친 저장분이 우선합니다. 사이트 편집 → **원본(config.js)으로 되돌리기** |
| 관리자 비밀번호를 잊었어요 | 사이트를 연 브라우저에서 F12 → Console에 `Store.hashPw(Store.baseConfig.security.salt, '새비밀번호', 20000)`을 입력하면 해시가 출력됩니다. 이 값을 `config.js`의 `security.adminHash`에 붙여 넣고 저장하세요. 그다음 Console에서 `localStorage.removeItem('kuc:config')`를 실행하고 새로고침하면 새 비밀번호로 열립니다 |
| 수강생이 로그인되지 않아요 | 명단에 등록되어 있는지, 비밀번호가 학번인지 확인. 관리자 화면 → 수강생 → **비밀번호 초기화** |
| 다른 기기에서 낸 데이터가 안 보여요 | 1번 항목의 한계입니다. 서버 연동이 필요합니다 |
| 브라우저 데이터를 지웠더니 기록이 사라졌어요 | 정기적으로 **설정·백업 → 데이터 백업**과 과제 파일 다운로드를 해 두세요 |
| 과제 파일이 저장되지 않아요 | 브라우저 저장 공간 부족일 수 있습니다. 파일 크기 제한을 낮추거나 오래된 과제를 내려받은 뒤 정리하세요 |
